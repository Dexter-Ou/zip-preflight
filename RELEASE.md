# ZIP Preflight 0.1.0 preview

Python 3.12+ standard library. Tested on Linux with Python 3.12.15.
Other operating systems and Python versions have not been tested.

Contents: zip_preflight.py (command), test_zip_preflight.py (eight synthetic
unittest methods), README.md (run steps, limitations and removal), LICENSE
(MIT), RELEASE.md (this note), SHA256SUMS (source integrity inventory).

No networking, dependency installation, extraction or persistent services in
the command. Keep originals and review the README before using reports.
No support response time or secure-extraction guarantee is offered.
